Design System for Flutter - tokens, components and UI primitives.

## Installation

```yaml
dependencies:
  flutty_ds: ^0.1.0
```

## Usage

```dart
import 'package:flutty_ds/flutty_ds.dart';

// Use color tokens
final color = FluttyColors.primary;

// Use spacing tokens
final padding = EdgeInsets.all(FluttySpacing.md);
```
